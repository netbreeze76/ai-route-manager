# 产品规格（当前实现 v1.0.0）

## 目标

用户只描述“AI 要稳定、下载要便宜、国内要直连、远控要低延迟”，软件负责订阅更新、节点健康、固定出口、应用分流和故障回退，不让用户在节点列表中反复手选。

## 核心模式

- **预览模式（默认）**：生成配置、探测端口和出口，但不修改系统代理。
- **托管模式**：软件管理独立核心与系统代理；只有预检通过才能切换。
- **兼容模式**：生成并导出 FlClash/Mihomo 等配置，不接管第三方程序。

## 功能域

### 线路与固定出口

- 导入多个 Clash/Mihomo 订阅、SOCKS5、Shadowsocks、Trojan、SSH 和 VPS。
- 自动更新订阅，节点消失时按地区、能力和健康重新绑定，不按易变节点名硬编码。
- 固定出口由“前置线路 → 用户配置的目标地区 VPS”组成，支持同地区批准出口兜底。
- 用户可配置两位地区代码、地区名称和优先节点关键词；实际出口必须通过目标地区与 AI 服务可达性双重探测。
- 旧版缺少地区字段的个人配置只在迁移时补为 `SG / 新加坡 / 李家坡2-直连`，公共产品逻辑不再固定某个国家或节点名。
- 全新用户只需填写稳定订阅和目标地区；下载订阅、节点关键词与固定 VPS 均为可选项。保存前会删除空白可选项，总览只报告实际保存的线路。
- Windows 旧版配置导入按“当前用户标准目录 → 系统标准目录 → 历史个人兼容目录”查找，不把特定盘符作为公共产品的唯一前提。
- 线路编辑先写 A/B 配置并隔离探测，成功后才原子切换。

### 场景分流

- AI：ChatGPT/OpenAI、Claude、Gemini/Google AI 等严格地区锁定。
- 下载：Telegram、YouTube、Steam CDN、模型与大文件走低成本大流量线路。
- 国内：中国大陆域名/IP 默认直连，并提供 DNS 泄漏和误代理检测。
- 流媒体：Netflix、Apple TV+ 按会话锁定出口，避免播放中地区漂移。
- Steam：商店/登录、下载 CDN、游戏 UDP 可分开路由；不做账户地区伪装。

### 多设备

- Windows/macOS 桌面端共用同一策略模型。
- Android 生成 Mihomo/FlClash 兼容 YAML；iPhone/iPad 生成 Shadowrocket 规则、固定出口 SIP002 URI 和本地 SVG 二维码。
- Apple TV 优先使用 tvOS VPN 应用或路由器侧策略。
- 移动端导出必须二次确认；文件写入当前用户下载目录的独立受限目录，失败整批清理，报告不回显 Token 或密码。
- Android 配置支持动态 stable/download provider、AI 严格固定出口、中国大陆直连和下载分流；Shadowrocket 当前以固定出口规则为主，低成本订阅通过同包订阅清单添加。
- OpenWrt / OpenClash 网关可通过系统 SSH 执行隔离预演、固定路径事务下发和一键回滚：候选只在 `/tmp` 解码并由现有 `clash_meta` 校验，应用只接管 `/etc/openclash/config/ai-route-manager.yaml`，同时保存原文件、UCI `config_path`/`enable` 和 SHA-256；检测到后续人工修改时拒绝回滚。
- 设备中心通过固定的只读 SSH 脚本读取 OpenWrt 版本、机型、OpenClash/WireGuard/OpenVPN、IPv6 默认路由、UPnP、DHCP 租约与 IPv6 邻居；脚本不接受前端命令，不写路由器。
- 局域网设备策略按 MAC 身份持久化，允许重命名并选择国内直连、AI、流媒体、低延迟游戏或大流量下载场景；重新扫描会保留已有选择，离线设备不会被静默删除。
- 已启用的设备策略在候选配置中以精确 IPv4 `/32` 与 IPv6 `/128` 源地址规则写入，位于中国大陆直连之后、最终兜底之前；DNS、IPv4、IPv6 与 LAN 访问配置同时生成。
- 网关部署不自动下载核心、不安装 OpenClash、不开放防火墙端口，也不把订阅 Token 或 VPS 密码放进 SSH 命令行、前端状态或报告。

### 远程控制

- 办公控制：RustDesk，直连优先，中继兜底。
- 高画质/游戏：Sunshine + Moonlight，硬件编码与动态码率。
- 路径顺序：同局域网 > UDP 点对点 > 自建近端中继 > 用户选择的 VPS 最后中继。
- 根据 RTT、丢包、抖动、上行与编码器自动选择 1080p/1440p/4K 预设。
- Windows 可在二次确认后通过 winget 精确安装 Sunshine/Moonlight 白名单包；不自动启动远控软件。
- RustDesk Server OSS 可通过系统 SSH 部署到用户填写的 VPS：版本锁定的 Docker Compose、hbbs/hbbr 状态验证、公钥回传和客户端参数复制；防火墙向导在二次确认后只开放 `21115/tcp`、`21116/tcp+udp`、`21117/tcp`，并提供等范围回滚。
- Sunshine 防火墙向导只允许 Windows 专用网络中的 `LocalSubnet` 或 Tailscale/Headscale `100.64.0.0/10`，不生成任意公网来源规则；应用与回滚都需要 UAC 确认。
- 路径实测后可把码率、编码器、捕获方式和 UPNP 禁用策略事务写入 Sunshine 官方配置；提交前后校验 SHA-256，保留完整备份，用户后续修改会阻断强制回滚。写入不重启 Sunshine、不改防火墙或系统代理。

### 诊断与恢复

- 事实分层：本机实测、远端实测、配置推断分别展示。
- 导出诊断包前隐藏订阅 Token、密码、私钥、Cookie 和完整节点地址。
- 保存最近一个工作配置、启动前快照和一键恢复入口。
- 脱敏诊断只导出已知结构化字段，不复制原始日志；非本机代理地址统一遮盖，并按保留天数清理旧包。
- 本机配置备份保存在 Windows Credential Manager 或 macOS Keychain；恢复只替换应用设置、推荐位和线路凭据，不自动切换当前网络。
- 托管模式由应用内监督器每 5 秒写入脱敏心跳；核心/监听异常时按 15/30/60/120/300 秒退避恢复，旧版冲突、预览模式和用户停止操作均不会被强行接管。
- Windows 使用当前用户、最低权限计划任务在登录时启动监督器，并配置失败后 1 分钟重启；macOS LaunchAgent 在异常退出后按节流策略重启。关闭托管会先挂起监督器并提交预览模式，避免“刚停止又被拉起”。

### 推荐中心

- 用户可配置自己的 VPS、VPN、硬件和软件推荐链接、优惠码、价格文案。
- 推荐项只在缺少能力、套餐不足或用户主动打开购买助手时展示。
- 启用推荐项必须使用 HTTPS，且必须清楚披露合作推广关系。
- 打开购买页前显示服务商、价格、优惠码、目标域名和链接关系说明；确认打开成功后才累计本机点击次数。
- 推荐配置和点击统计进入本机备份，不采集订单、支付信息或服务商账户数据。
- 排序结合质量、价格、匹配度和商业权重；商业权重不得绕过最低质量门槛。
- 产品方推荐从固定 HTTPS 地址下载，Rust 后端使用内置更新公钥验证签名后才接受；验签失败时 fail-closed，不展示未认证目录。
- 平台推荐带“签名发行”和目录版本标识，不能在客户端编辑或删除；用户本机推荐位与发行目录分开保存，并可单独关闭平台推荐。

### 签名更新

- Windows/macOS 更新包使用独立 Tauri updater 密钥签名；内置公钥只接受对应私钥产生的安装包。
- 正式更新清单默认使用 `https://139-59-246-27.sslip.io/ai-route-manager/latest.json`；也允许用户换成无账号密码、无片段的 HTTPS URL。自动检查只提示，安装必须由用户确认。
- Windows 更新安装退出桌面界面时不停止独立代理进程；登录/崩溃监督器继续保障入口。
- 发布脚本生成安装包签名和 `latest.json`，并验证版本、平台、HTTPS URL、签名文件一致性与 SHA-256。
- 私钥不进入源码、发布包或诊断包；本机发布密钥使用加密私钥和 DPAPI 保护的密码。

## 版本路线

1. **已实现**：完整 UI、策略规划、诊断、系统凭据存储、推荐位管理。
2. **已实现**：Mihomo sidecar、A/B 配置、隔离预演、系统代理事务、旧版无中断迁移和一键恢复。
3. **已实现构建链**：Windows 安装版/便携版；macOS 使用平台专属 Tauri 配置替换 Windows 资源列表，只打包独立 sidecar。本机验收模式无需发布私钥即可生成 ad-hoc DMG；正式模式强制 updater 私钥、Developer ID、公证凭据、staple 验证和包内哈希验证，且两种产物分目录保存。macOS 成品仍须在真实 Mac 上执行构建验收。
4. **已实现**：Android/Shadowrocket 移动端导出、固定出口二维码、敏感导出确认与事务清理；OpenWrt / OpenClash 家庭网关支持只读能力与设备发现、持久设备场景、DNS/IPv4/IPv6 源地址策略、远端核心预演、原子下发、UCI 切换、服务提交验证和冲突感知回滚。
5. **已实现**：RustDesk/Sunshine/Moonlight 安装与进程检测、白名单静默安装、目标端口多次握手实测、质量评分、配置导出、Sunshine 实测参数事务写入与冲突感知回滚、RustDesk OSS SSH/Docker 部署，以及本机 Sunshine 与远端 RustDesk 最小端口防火墙向导和等范围回滚。
6. **已实现基础版**：应用内心跳监督、核心故障退避恢复、Windows 计划任务 RestartOnFailure、macOS LaunchAgent KeepAlive；真实断网/杀进程演练将在不影响现有 AI 网络的隔离环境继续扩充。
7. **已实现并上线**：带签名安装包、正式 HTTPS 更新源、自动检查、手动确认安装、发布清单生成、本机私钥保护和远端发布复核。
8. **剩余商店级发布门槛**：Developer ID/Windows Authenticode 代码签名和 macOS 实机验收；不影响 updater 自身的强制签名校验。
9. **已实现并上线**：签名平台推荐目录、远端无缓存/CORS 分发、客户端验签、篡改拒绝和本机推荐隔离；真实 VPS/VPN 服务链接由产品运营者提供后再签名发布。
