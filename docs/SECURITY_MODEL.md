# 安全模型

## 不变量

1. 预览模式不写系统代理、不关闭现有代理进程、不接管端口。
2. 应用动作必须具有基线快照、候选配置、验证结果和可执行回滚。
3. 严格 AI 策略的失败结果是同地区批准出口或阻断，绝非静默 `DIRECT`。
4. 订阅 URL、访问令牌、VPS 密码和私钥只进入 Windows Credential Manager 或 macOS Keychain。
5. 前端状态、日志、诊断包和推荐配置不存放线路密钥。

## 配置事务

1. 读取当前工作状态并记录哈希。
2. 在独立目录生成候选配置。
3. 运行 schema、端口冲突、DNS、连通性和出口地区检查。
4. 启动候选 sidecar 到临时端口。
5. 验证关键域名与回退路径。
6. 原子切换；失败则恢复旧文件和旧端口。
7. 再次验证恢复后的行为。

## 推荐链接

- 链接协议必须为 HTTPS。
- 界面必须清楚显示合作推广关系。
- 跳转前展示服务商、价格说明和目标域名。
- 只有外部购买页成功交给系统浏览器后才增加本机点击计数；不把点击、订单或付款数据上传到产品方。
- 用户可关闭全部商业推荐并继续使用自有服务。
- 发行者目录只从无凭据、无片段的 HTTPS 地址下载，并限制为 2 MB；WebView 只负责获取字节，Rust 使用内置公钥验签。
- 目录载荷和签名任一处被改动、目录版本不受支持或推荐项校验失败时，所有平台推荐 fail-closed；旧目录不会作为未签名缓存继续展示。
- 平台推荐不会写入本机自定义推荐配置，界面不可编辑；本机备份与恢复也不会把远端目录伪装为用户配置。

## Sunshine 配置事务

- 只写入操作系统约定的 Sunshine 配置路径，不接受前端提供任意文件路径。
- 候选配置限制为 1 MB、UTF-8，并只管理捕获方式、编码器、最大码率、UPNP 和对应编码器调优字段；其他用户字段原样保留。
- 写入前记录原文件 SHA-256 和完整备份；提权提交时再次比较原哈希，避免检查后被替换。
- 回滚前要求当前文件仍等于应用后哈希；检测到用户或 Sunshine 后续改动时拒绝覆盖。
- 写入与回滚都不停止 Sunshine、不修改系统代理、防火墙、路由表或当前 AI 线路。

## OpenClash 家庭网关事务

- 前端不能提供远端脚本或目标路径；后端只接受 `preview|apply|rollback`，固定目标为 `/etc/openclash/config/ai-route-manager.yaml`，并要求 OpenWrt `root`、现有 OpenClash 服务和现有核心。
- 订阅与固定出口配置只以 Base64 数据进入 SSH 标准输入；SSH 参数、前端报告和错误只含主机、固定路径、核心标识、状态与 SHA-256，不回显 Token 或密码。
- `preview` 只在路由器 `/tmp` 解码、校验 SHA-256 并执行现有核心 `-t`，不写 `/etc`、不修改 UCI、不重启服务。
- `apply` 先保存目标文件、UCI `config_path`/`enable` 和应用哈希，再原子替换、切换 UCI 并重启；重启或提交复核失败时立即恢复原文件和原 UCI。
- `rollback` 只在当前目标哈希、UCI 路径和启用状态仍等于应用后状态时执行；人工修改会触发冲突拒绝。回滚重启失败时重新应用刚才的工作配置并保留回滚点。
- 网关脚本不调用下载器、包管理器、防火墙或电脑代理命令，不接受任意 shell、路径或服务名。
