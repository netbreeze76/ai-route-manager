# 赞赏、推荐与合法使用说明

## 发布前必做

1. 当前赞赏码为用户于 2026-11-06 提供的 `public/support-qr.jpg`，按原始比例展示并可点击放大。更换时保持原图，不裁剪、不重绘、不叠加文字或滤镜。
2. 使用至少两台手机和两个扫码应用复验，确认收款主体、金额选择和支付页均正确。
3. 每个返利链接必须使用 HTTPS，并在对应卡片的“链接关系说明”中明确写出开发者可能获得佣金或返利。
