# AI Route Manager 零基础安装与设置教程

适用版本：1.0.0

这份教程写给第一次使用代理分流软件的人。你不需要理解节点、路由表、DNS 或命令行，只要按顺序完成每一步。

## 一、先准备好这些东西

### 必须准备

1. 一台 Windows 10 或 Windows 11 的 64 位电脑。
2. AI Route Manager 安装包。
3. 一条稳定的 Clash/Mihomo 订阅 URL。这条线路负责 ChatGPT、Claude、Gemini 等 AI 服务。
4. 你希望 AI 长期使用的出口地区，例如美国、日本、新加坡或德国。

### 按需准备

1. 下载订阅 URL：用于 Telegram、YouTube、Steam 下载和大文件下载。最多可以填写两条，不需要就留空。
2. 固定出口 VPS：用于把 AI 的最终出口固定在某个地区。不使用 VPS 也可以先完成基础设置。
3. VPS 的 Shadowsocks 参数：服务器地址、端口、加密方式和密码。只有使用固定出口 VPS 时才需要。

### 开始前必须知道

- 订阅 URL 通常包含你的私人 Token，等同于账号密码，不要发到群里、论坛或截图中。
- 不要随意更换 AI 常用地区。长期使用同一个国家或地区通常比频繁跳区稳定。
- 如果电脑上已有 FlClash、Clash、Mihomo 或旧版 AI Route Manager，先不要强行退出。软件检测到旧入口后会显示“无中断迁移”。
- 第一次操作时一定按照“保存配置 → 安全预演 → 验证并应用”的顺序，不要跳步。

## 二、安装软件

1. 找到文件名类似 `AI-Route-Manager-版本号-Windows-x64-setup.exe` 的安装包。
2. 确认安装包来自你信任的发布者，并对照发布页面提供的 SHA-256。
3. 双击安装包，按照安装界面完成安装。
4. 安装完成后打开 AI Route Manager。

第一次打开时，右上角应该显示“预览模式”，左下角核心状态应显示“安全预览”或“旧版待迁移”。此时软件还没有主动切换系统代理。

如果 Windows 提示安装包来源未知，先停止安装并重新核对下载来源、文件名和 SHA-256。不要使用来源不明的二次打包版本。

## 三、填写第一套可用配置

打开左侧的“线路与 VPS”。

### 1. 填写稳定订阅

在“稳定订阅 URL”中粘贴你的稳定订阅地址。这一项必填。

稳定订阅主要负责：

- ChatGPT 和 OpenAI；
- Claude 和 Anthropic；
- Gemini 和 Google AI；
- 其他对出口地区和稳定性要求较高的服务。

### 2. 填写下载订阅

如果你有便宜、大流量的订阅，可以填入“下载订阅 1 URL”和“下载订阅 2 URL”。这两项都可以留空。

下载线路主要负责：

- Telegram 媒体下载；
- YouTube 和视频流量；
- Steam CDN；
- 模型文件和其他大文件。

### 3. 设置目标地区

目标地区代码必须是两个英文字母，例如：

| 地区 | 代码 |
| --- | --- |
| 美国 | US |
| 日本 | JP |
| 新加坡 | SG |
| 德国 | DE |
| 英国 | GB |

“目标地区名称”填写你自己看得懂的中文名称，例如“美国”或“新加坡”。

目标地区应该与你平时使用 AI 账号的地区保持一致。软件不会替所有用户固定成新加坡。

### 4. 设置优先节点关键词

这项可以留空。

如果订阅内有你特别信任的线路，可以填写节点名称中的关键词，多个关键词用逗号分隔，例如：

`专线, Premium, 低延迟`

不要把某个随时可能消失的完整节点名当成唯一选择。软件会结合地区和健康状态自动重新选择。

### 5. 设置固定出口 VPS

没有 VPS 时，服务器地址和密码都留空即可。

如果你已经有 Shadowsocks VPS，则填写：

- VPS 地址：域名或 IP；
- 端口：服务端提供的端口；
- 加密方式：必须与服务端一致；
- VPS 密码：必须与服务端一致。

固定 VPS 的地区应当与前面填写的目标地区一致。

### 6. 保存配置

点击“保存到系统凭据库”。

看到“连接配置已写入系统凭据库”后，说明订阅 Token 和 VPS 密码已经保存。普通日志和普通配置文件不会显示完整凭据。

## 四、运行安全预演

保存成功后，点击“运行安全预演”。

安全预演会在临时端口启动候选配置，检查订阅、节点、固定出口和实际地区。它不会直接替换你当前正在使用的网络。

成功时应当看到成功提示，并显示“临时凭据清理：完成”。

如果预演失败，不要继续应用。按照提示检查：

1. 稳定订阅是否过期；
2. 订阅 URL 是否粘贴完整；
3. 目标地区代码是否为两个英文字母；
4. 订阅中是否存在目标地区的可用线路；
5. VPS 地址、端口、加密方式和密码是否对应；
6. VPS 的真实地区是否与目标地区一致。

修改后重新保存，再次运行安全预演。

## 五、正式启用智能分流

安全预演成功后，回到左侧“总览”。

### 新电脑或没有旧版代理

点击右上角“验证并应用”。软件会再次验证，然后才切换系统代理。

### 检测到旧版代理

按钮会显示“无中断迁移”。点击它后，软件会先启动并验证新核心，再切换系统代理，最后停用旧入口。迁移过程中不要手动关闭旧代理或反复点击按钮。

成功后应看到：

- 右上角显示“托管模式”；
- 左下角显示“托管运行中”；
- 总览中的稳定入口显示正在监听；
- 按钮变为“停止并恢复”。

## 六、完成第一次验收

依次完成下面的检查：

1. 打开一个中国大陆网站，确认能够正常访问。
2. 打开 ChatGPT、Claude 或你常用的 AI，确认能够登录和对话。
3. 打开 Telegram、YouTube 或一个大文件下载，确认下载线路可用。
4. 打开“诊断中心”，点击“刷新本机实测”。
5. 确认运行模式为“托管模式”，本机入口处于可达状态。
6. 打开“设置”，开启“登录与崩溃自愈”。
7. 在“诊断中心”点击“创建备份”，建立第一个本机保险点。

完成以上检查后，日常使用时不需要再手动选择节点。

## 七、重启电脑后会怎样

开启“登录与崩溃自愈”后，登录 Windows 时监督器会自动检查托管核心和监听端口。

重启后可以这样确认：

1. 打开 AI Route Manager；
2. 查看左下角是否为“托管运行中”；
3. 打开“诊断中心”；
4. 点击“刷新本机实测”；
5. 再访问一次常用 AI。

如果显示“安全预览”，先不要反复安装软件。检查诊断提示，再点击“验证并应用”。

## 八、以后怎样修改线路

订阅到期、换服务商或更换目标地区时：

1. 打开“线路与 VPS”；
2. 修改对应内容；
3. 点击“保存到系统凭据库”；
4. 点击“运行安全预演”；
5. 预演成功后回到“总览”；
6. 点击“验证并应用”。

不要在托管运行中直接删除配置文件或手工结束核心进程。

## 九、怎样暂停并恢复原来的网络

回到“总览”，点击“停止并恢复”。

软件会停止托管，并恢复接管前保存的系统代理状态。这与直接在任务管理器中结束进程不同。

“诊断中心”里的“恢复配置”只恢复应用设置和凭据，不会自动切换系统代理。恢复完成后仍需点击“验证并应用”。

## 十、把配置导入手机

打开“设备中心”。

### Android

勾选“Android / Mihomo”，可以生成供 FlClash、Mihomo Party 等兼容客户端使用的配置。

### iPhone 或 iPad

勾选“iPhone / iPad”，可以生成 Shadowrocket 配置、固定出口 URI 和二维码。

导出前必须勾选凭据确认，然后点击“确认并导出”。

导出文件可能包含订阅 Token 或 VPS 密码。只传到自己的设备，导入完成后删除聊天软件、网盘和下载目录中的临时副本。

## 十一、让 Apple TV、Xbox 和全家设备使用分流

最稳定的方式是使用 OpenWrt/OpenClash 路由器或独立家庭网关。Windows 热点只适合作为临时方案。

### 使用前提

- 路由器运行 OpenWrt；
- 路由器已经安装并能正常运行 OpenClash；
- 路由器已经有可用的 Clash Meta 核心；
- 你拥有路由器的 root SSH 私钥；
- 电脑能够通过 SSH 访问路由器。

### 设置步骤

1. 打开“设备中心”。
2. 填写路由器地址、SSH 端口和 SSH 私钥的绝对路径。
3. 点击“扫描设备与能力”。这一步只读取信息，不修改路由器。
4. 为识别到的设备改名，例如“客厅 Apple TV”或“Xbox Series X”。
5. 为每台设备选择场景：国内优先、AI、流媒体、低延迟游戏或大文件下载。
6. 点击“保存设备策略”。
7. 点击“隔离预演”。
8. 预演成功后点击“应用并重载”。

需要恢复时点击“一键回滚”。如果路由器配置在应用后被其他人手动修改，软件会阻止覆盖式回滚，并提示先检查冲突。

AI Route Manager不会自动给路由器安装OpenClash，也不会自动开放路由器防火墙端口。

## 十二、远程控制功能怎样选

普通办公和帮助家人维护电脑，选择 RustDesk。

追求高画质、低延迟或远程游戏，选择 Sunshine 作为主机端、Moonlight 作为客户端。

推荐顺序是：

1. 同一局域网；
2. UDP 点对点；
3. 自建近端中继；
4. VPS 中继。

纯新手第一次配置代理时可以跳过“远程控制”。先确保基础分流稳定，再单独配置远控。

## 十三、推荐中心是什么

推荐中心用于展示可选的 VPS、VPN、软件和硬件服务。它不是完成基础配置的必需步骤。

打开服务商页面前，软件会显示服务商、目标网站、价格说明、优惠码和链接关系说明。付款和售后都在服务商网站完成。

不想看到平台推荐时，可以在“设置”中关闭“展示平台推荐”。

## 十四、最常见的问题

### 1. 国内网站也变慢了

打开诊断中心刷新实测，检查是否处于托管模式。国内域名和中国大陆 IP 默认应当直连。

### 2. ChatGPT 能打开，但经常重新验证

检查目标地区是否频繁变化，优先使用长期稳定的同地区线路。不要今天美国、明天日本、后天新加坡。

### 3. 安全预演一直失败

先只保留稳定订阅和目标地区，把下载订阅、优先关键词和固定 VPS 暂时留空。基础配置成功后再逐项添加。

### 4. 显示“旧版待迁移”

使用总览中的“无中断迁移”，不要同时手动启动多个旧版代理。

### 5. 重启后没有自动恢复

打开“设置”，确认“登录与崩溃自愈”已经开启，然后到诊断中心刷新实测。

### 6. 想回到修改前

仍在托管时点击“停止并恢复”。如果需要恢复应用配置，到诊断中心点击“恢复配置”，之后重新预演和应用。

### 7. 需要把问题发给技术支持

打开“诊断中心”，点击“导出诊断”。诊断包会隐藏订阅 Token、密码、Cookie 和完整节点地址。不要直接发送订阅截图或系统凭据库内容。

## 十五、最终完成清单

全部满足后，才算完成第一次设置：

- [ ] 稳定订阅已经保存；
- [ ] 目标地区代码和名称正确；
- [ ] 下载订阅按需要填写；
- [ ] 固定 VPS 按需要填写；
- [ ] 安全预演成功；
- [ ] 总览显示托管运行中；
- [ ] 国内网站正常；
- [ ] AI 网站正常；
- [ ] 下载线路正常；
- [ ] 登录与崩溃自愈已开启；
- [ ] 诊断中心已经创建备份；
- [ ] 订阅 URL、Token 和 VPS 密码没有发送给其他人。

完成后，软件会按照“国内直连、AI稳定、下载走大流量线路”的策略自动工作，日常不需要在节点列表中反复选择。
