# 推荐中心规则

- 产品运营者通过 `scripts/generate-referral-catalog.ps1` 生成发行者目录；未提供真实链接时发布空目录，不预置虚构或未核验的合作关系。
- 发行者目录使用与桌面更新相同的内置公钥体系验签，签名失败、载荷被改动或 schema 不受支持时整份拒绝加载。
- 用户本机填写的推荐项只保存在本机；下载到的发行者目录不进入本机推荐项持久文件或配置备份。
- 每个启用推荐项都必须填写 HTTPS 链接和合作推广关系说明。
- 同类别至少保留“使用我自己的服务”入口。
- 质量门槛优先于佣金：不可推荐已知不可达、地区不符或长期不稳定的服务。
- 记录点击时只统计推荐项 ID、时间和应用版本；默认不采集完整目标 URL、设备标识或浏览历史。
- 价格、优惠码和地区供应是易变信息，发布前应重新核验。
- 用户可在设置中只关闭平台推荐；本机自定义推荐项和“使用我自己的服务”入口不受影响。
