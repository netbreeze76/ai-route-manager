# AI Route Manager 家庭智能网关路线图

## 产品定位

AI Route Manager 不只管理一台电脑，而是由桌面端完成发现、配置、诊断与回滚，由路由器或独立网关长期执行全屋策略。用户选择设备和场景，不需要直接编辑 DNS、CIDR、防火墙或路由表。

## 三层执行架构

1. **原生网关代理**：优先支持 OpenWrt，桌面端部署签名组件；电脑关闭后仍可运行。
2. **现有 VPN 能力导入**：对支持 WireGuard/OpenVPN 的封闭固件生成配置，并明确标注是否支持策略路由。
3. **独立家庭网关**：对运营商封闭路由器提供可扫码绑定的小型旁路设备。

Windows 热点/ICS 只作为临时共享模式；Apple TV 客户端只作为补充；Xbox 不依赖设备端 VPN 客户端。

## 场景策略

| 场景 | 默认出口 | 关键约束 |
| --- | --- | --- |
| 国内优先 | DIRECT | IPv4/IPv6 与 DNS 同步直连 |
| AI 服务 | 固定地区线路 | 地区校验、账号稳定、失败关闭 |
| Apple TV 流媒体 | 高带宽线路池 | 流媒体域名与 CDN DNS 联动 |
| Xbox 登录/商店 | 对应地区稳定线路 | 保持账号地区一致性 |
| Xbox 游戏/语音 | 最低延迟或直连 | UDP、UPnP、开放 NAT 优先 |
| Xbox/主机下载 | 高带宽下载池 | 与低延迟游戏线路分离 |

## v1.0 已交付的软件能力

- 只读发现 OpenWrt 版本、机型、OpenClash/WireGuard/OpenVPN、IPv6 默认路由、UPnP、DHCP 租约与 IPv6 邻居。
- 按真实设备保存名称、固定 IP、MAC 与场景；再次扫描保留用户选择和离线记录。
- 生成 DNS、IPv4、IPv6、国内直连及设备源地址策略；AI 保持失败关闭，视频/下载与游戏使用不同线路池。
- OpenClash 候选在 `/tmp` 校验，固定目标原子替换，备份原配置和 UCI 状态，失败自动恢复，外部修改时拒绝破坏性回滚。
- 设备策略随本机加密备份一起导出/恢复；路由器端应用后由 OpenClash 自启动，Windows 无需常驻。

## 实机验收边界

- v1.0 的自动化测试使用固定 SSH runner 与配置 fixture，已经覆盖命令注入、规则顺序、IPv4/IPv6 合并、备份和回滚事务。
- Xbox NAT/UPnP/UDP 语音、Apple TV 多 CDN 解锁、具体路由器插件差异和断电重启仍必须在对应实机上验收；软件不会把 fixture 成功显示成实机已通过。
- 不支持 OpenClash 的封闭路由器不会被自动改写；后续通过原生 WireGuard/OpenVPN 导入或独立网关适配扩展。

## 后续硬件兼容与体验

- 华硕/梅林、GL.iNet 和原生 WireGuard/OpenVPN 导入。
- 游戏、商店、语音、下载拆分线路池。
- 设备页展示当前场景、实时出口、NAT、DNS、IPv6 和故障原因。
- 一键测速基于延迟、抖动、丢包、带宽和地区一致性综合选路。

## P2 小白硬件方案

- 预配置家庭网关，插电、插网线、扫码绑定。
- iOS/Android 管理端、家庭设备分组、可选家长控制。
- 脱敏远程诊断、签名更新、配置版本化和一键回滚。

## 验收门禁

1. Xbox NAT/UPnP、UDP 联机和语音不因策略路由退化。
2. Apple TV 流媒体与国内应用可同时命中正确出口。
3. DNS 与 IPv4/IPv6 规则一致，不发生旁路或泄漏。
4. VPN 失效不导致全家断网，严格服务不回落到错误地区。
5. 网关重启、线路刷新和核心轮换后策略自动恢复。
6. 所有部署均有哈希绑定备份、修改记录、验证报告和独立回滚。
