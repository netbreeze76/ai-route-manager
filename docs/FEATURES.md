# 功能与实现边界

本文记录 AI Route Manager 已实现的主要能力。README 只保留公共用户需要的下载、上手和支持范围；实现细节集中在这里维护。

## 桌面管理

- React/TypeScript 产品界面包含总览、线路与 VPS、场景分流、设备、远程控制、推荐中心、诊断和设置。
- Rust/Tauri 后端负责端口快照、配置校验、原子保存、系统凭据库、更新与平台集成。
- 安全预览模式只读取既有本机入口，不会在用户确认前接管或重启当前代理。
- 首次配置要求稳定订阅与目标地区；下载订阅和固定 VPS 可以按需添加。

## 地区与出口策略

- 用户可以填写两位地区代码、显示名称和多个优先节点关键词。
- 固定 VPS、订阅节点筛选、出口健康检查和移动端导出共同使用同一地区策略。
- AI 严格出口没有批准的同地区出口时阻断，不会故障回落到 `DIRECT`。
- 中国大陆服务保持直连；普通境外流量不会被意外送入 AI 固定出口。
- 旧版本配置会迁移到等价的地区策略；全新安装不会预设国家或作者个人节点。
- 旧版本自动导入优先使用当前用户与系统标准数据目录；公共版本不依赖作者的磁盘路径。

## 凭据、更新与诊断

- 订阅令牌、VPS 密码和私钥不会进入前端日志或普通配置文件。
- Tauri 更新使用 HTTPS 清单、内置公钥验证、自动检查、用户确认安装和发布清单生成。
- 安装包、签名和发布清单在发布流程中校验 SHA-256 与 Tauri 签名。
- 诊断归档会过滤完整订阅地址、密码、Cookie、令牌、私钥和原始核心详情。
- 推荐中心区分用户本机推荐与发行者目录；发行者目录验签失败时拒绝加载。

## 远程控制

- Sunshine 防火墙向导仅开放专用网络所需的最小端口，并提供对称回滚。
- Sunshine 配置写入采用原文件哈希门禁、完整备份、用户改动冲突拒绝和一键恢复。
- RustDesk VPS 向导仅配置原生客户端所需的最小端口，部署输入采用固定脚本和严格校验。
- 远控操作不会顺带重启网络代理；安装第三方远控组件需要用户单独确认。

## OpenWrt / OpenClash

- 使用只读 SSH 自动发现 OpenWrt 能力、DHCP/IPv6 邻居和局域网设备。
- 支持按设备保存国内直连、AI、流媒体、游戏或下载场景。
- DNS、IPv4 和 IPv6 策略进入同一个可回滚候选配置。
- 下发流程包含 SSH 隔离预演、核心语法校验、固定目标原子写入、UCI 选择切换和服务重启验证。
- 服务重启失败时恢复上一个验证版本；检测到用户外部改动时拒绝覆盖。
- 软件不会自动安装路由器组件，也不会在配置家庭网关时修改电脑代理。

## 平台与构建

- Windows 公开版打包 Windows 引擎和资源，不混入 macOS sidecar。
- macOS 构建只打包 `engine-macos`；本机测试默认生成 ad-hoc DMG。
- `--release` 模式要求更新签名、Developer ID 和 Apple 公证凭据，并验证 stapled ticket。
- Windows、macOS 测试包和正式发布包使用独立输出目录。

## 推荐与商业关系

- 推荐位支持 VPS、VPN、软件和硬件服务链接、优惠码与合作关系披露校验。
- 直接赞赏与推荐返利分开展示；返利链接必须说明开发者可能获得佣金。
- 用户可以关闭发行者推荐，同时保留本机自定义推荐位。
- 推荐服务不影响用户使用自有线路、VPS 或远控工具。
